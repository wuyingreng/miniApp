表单 name 属性详解

1. 基础示例 - 为什么需要 name 属性

name 属性的作用：
  • 标识表单字段，用于数据收集
  • 表单提交时，只有带 name 属性的字段才会被收集
  • 后端可以通过 name 属性识别前端传来的数据

2. 微信小程序中的 name 属性

<form bindsubmit="onSubmit"> <input type="nickname" name="nickname" placeholder="请输入昵称" /> <input type="text" name="username" placeholder="请输入用户名" /> <button form-type="submit">提交</button> </form>
// JavaScript 中获取数据 onSubmit(e) { const formData = e.detail.value console.log(formData.nickname) // 获取昵称 console.log(formData.username) // 获取用户名 }
注意：在微信小程序中，type="nickname" 是特殊类型，会调起微信的昵称输入键盘，但仍然需要 name 属性来标识数据。

5. 最佳实践

命名规范：

  • 语义化命名：使用有意义的 name 属性，如 name="email" 而不是 name="field1"
  • 一致性：保持命名风格一致，如使用驼峰命名法或下划线命名法
  • 简洁明了：name 属性应该简洁但能清楚表达字段用途
// 推荐：语义化的 name <input type="text" name="username" /> <input type="email" name="email" /> <input type="password" name="password" /> // 避免：无意义的 name <input type="text" name="input1" /> <input type="email" name="field2" /> <input type="password" name="data3" />
